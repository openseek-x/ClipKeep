## 1. 任务概述、范围与方案

发布 v1.1.1，交付 AI 输入/输出可选限制修复：

- 新配置默认不设置客户端输入字符限制。
- 新配置默认不向 Provider 发送输出 token 上限。
- 用户启用限制后可直接键入或粘贴任意正整数。
- 旧配置中的正数限制保持不变。
- 保留文本入库、请求超时、流式响应和图片大小等资源安全硬边界。

本次是向后兼容的设置和请求参数修复，因此采用补丁版本 v1.1.1，而不是新增次版本。

非目标：不修改 AI Provider 类型、数据库、剪贴板历史、权限、架构或 v1.1.0 标签。

## 4. 问题、技术决策与偏差

- 发布过程没有阻断性故障，执行路径与发布方案一致。
- `0` 表示不设置客户端业务限制；正数表示启用限制。
- 输出不限通过省略 Provider 参数表达，不发送 `0` 或 `null`。
- 旧正数配置不自动迁移，避免覆盖用户主动设置的成本控制。
- 正数不设客户端最大值；过大数值可能由 Provider 返回 4xx，沿用现有错误展示。
- 资源硬边界没有删除，因此“不限制”不代表进程资源或模型上下文无限。

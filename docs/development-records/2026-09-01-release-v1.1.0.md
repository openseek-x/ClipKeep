## 1. 任务概述与发布方案

### 目标与范围

发布 ClipKeep v1.1.0，交付以下能力：

- 用户显式触发的文本与图片 AI 处理。
- OpenAI Responses 与 OpenAI-compatible Chat Completions Provider。
- 自定义 Base URL、API Key、模型及 Keychain origin 隔离。
- 图片缩放副本、Vision OCR 敏感扫描和逐次上传确认。
- 列表行尾 AI、收藏、删除快捷操作。
- 设置输入框标准 `Cmd+V/C/X/A` 编辑能力。
- 本地回环模型与可选局域网模型连接支持。

### 非目标

- 不执行生产数据库、系统配置或用户历史数据迁移。
- 不自动启用 AI，不上传既有剪贴板历史。
- 不发布 Intel 构建，不增加 Apple 公证。
- 不在本次发布中验证任何用户的真实 API Key 或发送真实剪贴板内容。

### 发布路径

1. 从本地 `master` 创建的 `codex/ai-actions` 完成功能开发与验证。
2. 首次使用 `git push -u origin codex/ai-actions` 推送任务分支。
3. 快进合并到本地 `main`。
4. 运行 `release.sh 1.1.0`：版本同步、构建、DMG、EdDSA 签名、自检、版本提交和标签。
5. GitHub API 中断后按现有断点恢复 Release 资产和 `gh-pages` appcast。

采用 v1.1.0 而非 v1.0.2，因为这是向用户新增可选 AI、多模态和交互能力的向后兼容功能版本。

## 3. 问题、根因与恢复

| 问题 | 根因 | 恢复与结果 |
|---|---|---|
| `gh` 初始认证失效 | Keyring 中旧 OAuth Token 无效 | 经 GitHub Device Flow 重新授权 `openseek-x`；最终 `gh auth status` 显示 active 且具备 `repo` scope |
| DMG Finder 布局进程被 `Killed: 9` | `package-dmg.sh` 的可选 AppleScript 布局达到 25 秒保护上限 | 脚本按设计跳过布局并继续；最终 DMG、签名与镜像验证均通过 |
| `gh release create` 首次发生 TLS handshake timeout | GitHub API 网络握手超时 | `main` 和标签已推送，Release 尚未创建；没有重跑发布脚本或重复递增构建号 |
| 合并创建 Release 与上传资产返回 HTTP 400 | GitHub uploads 端点在长连接后失败，失败事务未保留 Release | 改为两阶段：先创建无资产 Release，再用 `gh release upload --clobber` 上传；回读成功 |
| 原发布脚本在 Release 失败后未生成 appcast | `set -e` 在 API 错误处终止 | 使用 Sparkle 官方 `generate_appcast` 从同一 DMG 自动提取元数据并签名，再提交 `gh-pages` |

恢复过程中始终先回读远端对象，未重复创建标签、未强推、未删除 Release 或用户数据。

## 4. 技术决策与偏差

- 发布脚本原计划一次完成。由于远端 API 超时，实际改为断点恢复；版本号、构建号和标签保持原值。
- 恢复 appcast 时使用 Sparkle 官方 `generate_appcast`，而非手工复制脚本中的 XML 模板。
  生成器额外写入 arm64 硬件要求，并自动保证长度、签名和最低系统版本一致。
- GitHub Release 资产采用两阶段上传，降低“创建成功但资产失败”无法独立重试的耦合。
- 未因 UI 自动化不可用而把编译成功描述成功能验收；相关风险继续保留。

## 5. 配置文件变更与环境影响

### `Resources/Info.plist`

- 版本从 `1.0.1 (2)` 更新为 `1.1.0 (3)`。
- 本功能版本同时包含：
  - `NSAppTransportSecurity.NSAllowsLocalNetworking = true`，仅声明本地网络 ATS 例外；代码仍禁止远程 HTTP。
  - `NSLocalNetworkUsageDescription`，macOS 15+ 仅在用户实际连接局域网模型时可能提示。

### `settings.json`

- 新增可选 `ai` 配置对象，默认 `enabled = false`。
- 旧配置缺少该字段时兼容解码，无需手工迁移。
- API Key 不写入配置，按 Provider + origin 存入 macOS Keychain。

### 构建与发布配置

- `build.sh` 增加 Security、ImageIO、Vision framework 和新增 Swift 源文件。
- `gh-pages/appcast.xml` 更新到版本 1.1.0 / 构建 3。
- 无 secrets、Token 或私钥进入 Git 仓库、Release notes 或 appcast。

## 6. SQL、Schema 与数据迁移

本次没有 SQL 语句、数据库 Schema 迁移、数据回填或回滚语句。

既有 `clips` 表结构不变。AI 结果只有用户点击“保存到历史”时才复用现有 `upsert` 写入；
升级、启用或关闭 AI 都不会批量修改已有历史记录。
